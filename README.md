CARTZEE – Your Shopping Universe 🛍️ | An AI-enhanced full-stack e-commerce platform built with HTML, CSS, JavaScript, Java Spring Boot, Spring Security, JWT and MySQL. Features smart product search, shopping cart, wishlist, festival offers, order tracking and AI-powered shopping recommendations.
# CARTZEE – Your Shopping Universe

### Discover. Pick. Enjoy.

**CARTZEE** is an AI-enhanced online shopping cart system designed to provide a smarter, faster, and more personalized shopping experience.

## Key Features

- **My Picks** – Add, remove, and manage cart items.
- **Bucket List** – Save favorite products.
- **Hunt** – Smart product search and filtering.
- **CategoryHub** – Explore product categories.
- **Festival Offers** – Seasonal discounts and promotions.
- **Cartzee AI** – Intelligent product recommendations.
- **RateNest** – Product ratings and reviews.
- **Trackify** – Order tracking and delivery updates.
- **ShopHistory** – Previous order details.
- **QuickDrop** – Simulated express delivery.
- **Admin Dashboard** – Manage products, inventory, offers, and orders.

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Java 17+, Spring Boot, Spring Security, REST APIs
- **Database:** MySQL
- **Tools:** Maven, JWT, Git, GitHub, Google OAuth 2.0
